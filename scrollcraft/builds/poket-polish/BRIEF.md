# Poket School homepage polish

This is a focused update to an approved design, not a new site. User direction: “other than that everything is perfect” and “add some animations in it smooth animations using @scroll craft skill mke it look premium”. Existing content, assets, order, colors, and structure are authoritative. No new asset generation, cinematic pinning, replacement engine, or redesign is needed.

## Brief and authored motion decisions
1. Vibe: preserve the supplied airy, blue, illustrated design; motion should feel calm and precise.
2. Journey: existing hero → pathways → features → comparison → progress → pricing → CTA/footer.
3. Energy: strongest depth in the hero; restrained entrances; quiet pricing.
4. Feeling curve: curiosity (hero depth), orientation (pathways), discovery (cards), clarity (comparison), confidence (progress drawing), control (pricing), invitation (closing CTA).
5. Signature: the learning phone lifts slightly against slower cloud planes as scrolling moves it into the foreground mist. The scene stays inside its own hero.
6. Range: premium-minimal polish of the approved playful illustration style.
7. Distinct scenes in natural flow. No pinned or extra scroll sections.
8. Assets: existing CSS clouds, SVG owl, HTML phone and chart. No assets generated.

## Grammar and peak
Preserve existing product-story grammar. Other grammars would change the design the user explicitly approved. Peak: “The little learning world has depth as I scroll past it.” This belongs in the already-largest hero section. Tell-someone sentence: “It's the site where your pocket classroom lifts through the clouds.” Quiet pricing is intentional, not dead scroll.

## Scroll score and layer contract
| Scene | Device | Behavior |
| --- | --- | --- |
| Hero | Natural-scroll parallax | Stable copy; slow far clouds; phone rises at a separate rate; foreground mist stays anchored. No copy/CTA occlusion. |
| Features | One-time staggered entrances | Short vertical movement; content is visible without JS; keyboard focus cancels entrance. |
| Comparison | Paired entrances | Each existing comparison panel settles once without changing their widths. |
| Progress | Transform-based chart build | Bars grow to existing illustrative values once; no invented counters. |
| Pricing | Interaction feedback | Restrained hover/focus treatment; real plan calculations retained. |
| Closing CTA | Short reveal | The existing phone settles into the frame; ending stays fully visible. |

Mobile: smaller entrance travel; no hero parallax under 641px; preserve portrait composition and scrollable pathway links. Reduced motion: no animated entrance, chart growth, or parallax. No continuous animation loops or pointer capture.

Fingerprint: no previous registry entries. This is intentionally the same design, so the new-build differentiation gate does not apply.
